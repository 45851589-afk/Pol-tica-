Guías de Protección y Buenas Prácticas

Protocolos normativos obligatorios para todo el equipo de desarrollo de TurLux.

Gestión de Usuarios y Permisos Minimizados Requisito Base

Se aplica el principio de menor privilegio (PoLP). Ningún desarrollador opera bajo la cuenta root para tareas habituales. La elevación de privilegios se realiza mediante sudo auditado y con autenticación multifactor (MFA).

Resguardo de Credenciales y Claves Privadas Seguridad Operativa

Queda estrictamente prohibido hardcodear contraseñas, tokens de API o claves SSH en los repositorios de código Git. Se debe hacer uso exclusivo de variables de entorno cifradas y gestores de secretos autorizados.

Estrategia de Copias de Seguridad (Backups) Continuidad

Implementación de la regla 3-2-1 para copias de seguridad: tres copias de los datos, dos medios distintos y una copia cifrada fuera de la instalación local (Offsite) con pruebas periódicas de restauración.

Análisis de Amenazas y Riesgos

Ingeniería Social & Phishing

Riesgo: Robo de credenciales de acceso a la red interna.

Mitigación: Autenticación FIDO2/Hardware y capacitaciones trimestrales antiphishing.

Inyección de Código & Dependencias

Riesgo: Vulnerabilidades en paquetes nativos Linux de terceros.

Mitigación: Auditoría automatizada de software (SAST) y análisis de librerías.
